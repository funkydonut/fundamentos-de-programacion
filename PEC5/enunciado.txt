OBJETIVO
--------

Implemente un programa en C que compare dos pedidos de pizza de diferentes
establecimientos e indique cuál es la mejor opción.

  • El programa solo comparará los pedidos si el nombre de la pizza es el mismo.
    En caso contrario, mostrará "NON-COMPARABLE ORDERS" y el programa finalizará.

  • Para gestionar los datos, utilizaremos una tupla que contendrá la descripción
    (nombre de la pizza), precio base, descuento, distancia y precio final.

  • La mejor oferta será la que tenga el precio final más bajo. En caso de empate,
    se escogerá la que tenga el precio base más bajo. Si el empate persiste, se
    elegirá el segundo pedido introducido por teclado.


ENTRADA DE DATOS
----------------

El programa leerá desde teclado los datos del primer pedido y, a continuación,
los datos del segundo. Para cada pedido se solicitará:

  • La descripción: el máximo de caracteres permitidos será 50.

  • El precio base: un valor que puede contener decimales.

  • El descuento: un valor entero comprendido entre 0 y 10. Si el pedido no tiene
    descuento, el valor será 0. Es un valor absoluto, no un porcentaje.

  • La distancia en km: un valor que puede contener decimales.

La entrada de datos debe realizarse utilizando una acción que tenga como parámetro
de salida una tupla pedido.

Una vez leídos los datos de un pedido, se utilizará una acción para calcular su
precio final. Esta acción recibirá una tupla pedido como parámetro de entrada/salida
y actualizará un campo adicional de dicha tupla que contendrá el precio final,
basándose en las siguientes operaciones:

  1. Aplicar el descuento asociado al pedido sobre el precio base.

  2. Añadir los gastos de envío según la distancia:
        – Si la distancia es menor de 5 km, se suman 2 €.
        – Si la distancia es igual o mayor de 5 km, se suman 5 €.

  3. El precio final será:

        precio final = precio base − descuento + gastos de envío


SALIDA DE DATOS
---------------

El programa mostrará por pantalla todos los datos del pedido con la mejor oferta.
La salida de datos debe realizarse utilizando una acción que tenga como parámetro
de entrada una tupla pedido.

Para realizar la comparación entre ambos pedidos, se utilizará una acción con tres
parámetros, todos de tipo tupla pedido: dos de entrada, correspondientes a los dos
pedidos a comparar, y uno de salida, que contendrá los datos del pedido con la
mejor oferta.

Es obligatorio que los datos de cada pedido se guarden en variables de tipo de
datos estructurados (tupla). Además, también deben utilizarse las acciones descritas.

Finalmente, es necesario que el programa esté modularizado en 3 archivos:

        main.c    order.c    order.h
